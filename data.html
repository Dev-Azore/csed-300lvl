Data & AI Path

The Brain Track.

In this track, we learn how to use information to build smart tools. We find answers in numbers and share them with the world.

Track Leader

Umar Rufa'i

Data Scientist

Umar Rufa'i is a expert in solving puzzles with data. He helps students learn how to find hidden stories in numbers. He loves using smart tools to help communities make better decisions.

What you can learn:

📊
Data Analysis

Learning how to clean and look at data to find out what is really happening. You will make charts that tell a story.

🤖
Machine Learning

Teaching computers how to learn from data. You will build tools that can predict things or recognize patterns.

🗄️
Data Engineering

Setting up the pipes that move data from one place to another. You will make sure the data is always ready when we need it.
