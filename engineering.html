Engineering Path

The Building Track.

In this track, we learn how to make software. We build the things that users see and the magic that makes them work.

Track Leader

Salisu Ali

Full-Stack Engineer

Salisu Ali loves building things that work on the web. He helps students learn how to code from the front to the back. He believes that everyone can learn to build great apps if they have friends to help them.

What you can learn:

🖥️
Frontend Development

Making the part of the website that people see and touch. You will learn how to make layouts and buttons look great.

💾
Backend Development

Building the part of the app that stores information and handles logically complex tasks. This is the brain of the app.

🏗️
Full-Stack Development

Learning how to build the whole thing by yourself. You will understand how everything works together from start to finish.
