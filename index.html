The roadmap

Five phases.
One cohort. Real impact.

Each phase builds on the last — trust before tasks, tasks before teaching, teaching before legacy.

I
Weeks 1–4 Trust before tasks

Foundation

Build shared identity before building anything else.

🏛️
Community Setup
  • Community charter & shared values session
  • Group name, identity, and public channels
  • Roles assigned — volunteer first round
  • Onboarding buddy system paired
🔍
Skills Audit
  • Each member rates 5 core tech skills
  • Soft skills self-assessment form
  • Interest mapping to 2 skill tracks
  • Mentor matching based on audit
🎯
Goal Setting
  • Personal 3-month goal cards written
  • Team OKRs set collectively
  • Accountability partners assigned
  • First project themes brainstormed
🎤
First TechTalk
  • Lead member gives first TechTalk
  • Topic: growth mindset in tech
  • Q&A + group reflection
  • Ritual introduced and explained
II
Weeks 5–8 Clarity before execution

Project Discovery

Find the right problem before writing a single line of code.

🧭
Problem Scouting
  • Needs survey sent to the full class
  • Problem statements gathered and ranked
  • User research sprint (2 days)
  • Top 3 problems shortlisted together
🗺️
Solution Mapping
  • Cross-track brainstorm — all 4 tracks together
  • Tech feasibility check per solution
  • Solution voted on by the full group
  • Project scope document drafted
👥
Team Formation
  • Cross-track teams of 3–4 members formed
  • Each team: engineering + data + design + devops
  • Roles and responsibilities defined
  • Team contract signed by all members
📋
Sprint Zero
  • GitHub repo and project board set up
  • Tech stack decided as a team
  • First sprint backlog populated
  • Definition of Done agreed on
III
Weeks 9–16 All tracks. One product.

Build

The engine room — all four tracks converge to ship something real.

⚡
Project Sprints
  • 2-week sprint cycles with check-ins
  • Mid-sprint review with track leads
  • Weekly TechTalk rotates among members
  • Monthly peer review sessions (all tracks)
🎙️
Soft Skills Lab
  • Workshop 1: public speaking fundamentals
  • Workshop 2: leadership under pressure
  • Workshop 3: ownership mindset
  • Workshop 4: team conflict resolution
🔎
Peer Reviews
  • Monthly cross-track code review sessions
  • Structured feedback framework used
  • GitHub PR culture introduced
  • Pair programming blocks scheduled
🌐
External Exposure
  • Industry guest speaker (virtual)
  • Virtual job shadow opportunity
  • Members build LinkedIn profiles
  • Build in public — post across social platforms
IV
Weeks 17–22 Paying it forward

Scale & Teach

The community grows beyond the cohort — members become the teachers.

📚
Teach the Class
  • Weekly workshops open to the full class
  • Each 300-level member leads one session
  • Topics from a class-wide skills gap survey
  • Recorded and added to the knowledge base
🚀
Advanced Projects
  • Projects scope up — add real users
  • Deploy to production environments
  • Open-source at least one project
  • Partner with a student org or NGO
🔄
Leadership Rotation
  • New leads voted in by peers
  • Outgoing leads mentor incoming team
  • Retrospective on phases 1–3 done
  • Personal growth portfolios started
💚
Community Health
  • Burnout check-in survey sent
  • Celebration of wins — big and small
  • Community culture document updated
  • New rituals proposed by members
V
Weeks 23–26 The grand finale

Demo & Legacy

Showcase what was built. Hand the torch to who comes next.

🏆
Final Demo Day
  • Public showcase — all projects presented
  • Invite industry professionals & faculty
  • Each member presents their track work
  • Press-style Q&A panel after demos
💼
Portfolio Finish
  • Personal tech portfolios completed
  • GitHub profiles polished and pinned
  • Case studies written for each project
  • LinkedIn recommendations exchanged
📖
Legacy Handoff
  • Full program playbook documented
  • Resource library handed to the next class
  • Mentorship links to 200-level juniors
  • Community charter updated and archived
🎊
Celebration
  • Recognition ceremony for all members
  • Awards: Most Improved, Best Teacher…
  • Group reflection journal published
  • Community officially passes the torch
Skill tracks

Pick your lane.
Collaborate across all four.

Every member picks one lead track and one support track. Projects are always cross-track — the real learning happens at the intersections.

⚙️
Engineering

Full-stack, backend, mobile, systems. Code reviews, pair programming, and open-source contributions form the backbone of this track.

React / Next.js Node / Python APIs Open Source
📊
Data & AI

ML pipelines, analytics dashboards, and data storytelling using real datasets from NGOs and local organisations.

Python / SQL ML Models Dashboards NLP
🎨
Product & Design

User research, wireframing, and product thinking. This track ensures the group builds things people actually want to use.

Figma UX Research Prototyping Product Strategy
🛡️
DevOps & Security

CI/CD pipelines, cloud deployments, and security fundamentals. This track keeps the systems running reliably and safely.

Docker / K8s AWS / GCP CI/CD Security

Every project team includes at least one member from each track. Real products require all four disciplines working in concert.

Soft skills curriculum

Technical skills open doors.
These determine how far you go.

Monthly workshops woven into the program — not optional extras bolted on after the fact.

🎤
Public Speaking

Weekly TechTalks build confidence through low-stakes, high-frequency repetition. Every member speaks at least once per phase.

👑
Leadership

Roles rotate every semester. Members lead, follow, and mentor. Leadership is a practice, not a permanent title.

🔥
Ownership Mindset

When something is broken, the community fixes it — regardless of whose responsibility it formally is. Workshop 3 explores what this looks like in practice.

🤝
Conflict Resolution

Disagreements are a natural part of collaboration. The goal is learning to navigate them without damaging the relationships that matter.

✍️
Technical Writing

READMEs, case studies, LinkedIn posts. Clear written communication is a discipline most engineers undervalue until it's too late.

🧠
Growth Mindset

The opening TechTalk sets the tone for the entire program: failure is data, feedback is a gift, and learning has no endpoint.

Community rituals

Structure creates freedom.

Rituals are the heartbeat of the program — consistent, intentional, and owned by the community itself.

🗣️
Weekly
TechTalk (30 min)

One member teaches something they have learned. Rotates every week. No slides required — just knowledge shared openly.

🔎
Monthly
Peer Review Session

Cross-track code and design reviews. Members learn to give and receive professional, constructive feedback.

🚀
Monthly
Demo Day

Each team presents progress publicly — to peers, invited professionals, and the wider class.

🎙️
Monthly
Soft Skills Lab

Rotating workshops covering public speaking, leadership, ownership mindset, conflict resolution, and more.

🔁
Per phase
Retrospective

A structured team reflection — what worked, what did not, and what changes for the next phase. Written and shared openly.

📣
Ongoing
Build in Public

Progress, learnings, and wins posted on LinkedIn and other platforms. Build a professional presence while building the product.

Leadership structure

Everyone leads.
Everyone follows.

Roles rotate each semester — merit-based, peer-voted, and mentored. No one holds a title permanently, and no one leaves without having held one.

👑
Community Lead

Sets overall direction, manages external relations, and makes final calls. Rotates each semester.

🌿
Track Leads ×4

Own their skill track, set quality standards, and pair senior members with those who need support.

📅
Events Coordinator

Plans Demo Days, TechTalks, and external speaker sessions from start to finish.

💬
Community Manager

Onboards new members, tracks engagement, and keeps the culture healthy and welcoming.

📚
Knowledge Lead

Maintains the shared wiki, documents learnings, and curates the community resource library.

All roles rotate each semester, decided by peer vote
